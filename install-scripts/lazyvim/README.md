# LazyVim Installation

This script is meant to install LazyVim with defaults and then apply some customized configurations.

The goal is to use default settings with as many things as possible to allow for a convention > customization approach.

## Requirements

Be sure to install all the requirements within the `requirements.txt` file.

On Arch, you can use the following command:  
`yay -S $(cat requirements.txt)`

## Installation

Run the `./setup` script and the default LazyVim configuration will be installed.

NOTE: For the specific user configurations, review the `[nvim](../../nvim)` config folder
